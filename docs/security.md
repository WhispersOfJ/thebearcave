# Security

How secrets are handled, what's exposed, and the deliberate tradeoffs.

---

## Secrets model

| Layer | What | Gitignored |
|-------|------|-----------|
| `.env` | All runtime secrets + config | ✅ |
| `secrets/` | Docker-secret source files (generated by `setup.sh`) | ✅ |
| `services/<app>/config/` | App DBs and configs (contain API keys in the clear) | ✅ |
| `services/nzbdav-rclone/rclone.conf` | WebDAV credentials (rclone-obscured) | ✅ |
| `.env.template` | Documented placeholders — safe to commit | ❌ (committed) |

**Rules:**
- Never commit `.env`, `secrets/`, or any `services/*/config/`
- The CI `validate` workflow verifies every `${VAR}` in compose has a template entry
- The commit-time secrets scan (staging check) catches rclone.conf/.env/pfx/pem/key leaks

## What's exposed on the network

| Surface | Exposure | Notes |
|---------|----------|-------|
| Plex :32400 | LAN | Host network; unauthenticated control port — keep LAN-only or put auth in front |
| Traefik :80/:443 | LAN (or WAN if you open it) | Dashboard basic-auth protected |
| All service UIs | LAN via nip.io hostnames | No auth on most (*arr apps, Seerr, InfiniDysk) — LAN trust model |
| Metacache :8765 | LAN | Provider API unauthenticated by design (Plex sends no auth); write endpoints locked with `METACACHE_API_KEY` |
| Control Panel :8420 | LAN | docker.sock access — **highest blast radius**; mitigated by Origin/Host validation |

## Deliberate tradeoffs

1. **Control Panel privilege model** — docker.sock (RW), `pid: host`, `/sys/fs/fuse`
   (writable) enable Force Unstick and FUSE recovery. These are the exact powers that
   make it dangerous if exposed. Keep it LAN-only.
2. **Control Panel auth** — session login exists but several endpoints are effectively
   unauthenticated with Origin/Host checks only. This matches the original stack's
   decision; revisit if the panel ever leaves the LAN.
3. **`CONTROL_PANEL_SECURE_COOKIE`** — leave empty on plain-LAN HTTP. Set it **only**
   when a TLS reverse proxy fronts the panel, or every login silently fails.
4. **rclone RC** — password-protected (`NZBDAV_RCLONE_RC_PASS`) but that's the password
   InfiniDysk uses to push cache-forget notifications; keep it unique.

## CI security gates

| Gate | Where | Fails on |
|------|-------|----------|
| Trivy image scan | `trivy-scan.yml` | Any CRITICAL CVE in compose images |
| Trivy IaC scan | `trivy-scan.yml` | HIGH/CRITICAL Dockerfile/compose misconfigs |
| NuGet CVE audit | `dotnet-ci.yml` | Any vulnerable NuGet package |
| CodeQL | `codeql.yml` | Python/C# security findings |
| Secret leak prevention | repo hygiene | `.env`, keys, certs in git history |
| Dependabot | `dependabot.yml` | Weekly dependency bump PRs |

## Platform notes

- **Linux only** — `host.docker.internal` gateway resolution
- **FUSE** requires `SYS_ADMIN` + `/dev/fuse`; keep the `cap_add` on nzbdav_rclone
- cAdvisor runs `privileged: true` (host `/` read mounts) — it's the price of
  container metrics; keep it on the private network

## Incident response

1. Suspected leak? Rotate the affected key **now**, then find how it leaked
2. `git log -p` the history for anything committed by accident
3. If a secret hit the public repo: rotate it, and consider it burned forever
4. Update `.gitignore` if the leak path isn't covered
