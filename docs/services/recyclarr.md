# Recyclarr

Recyclarr syncs the [TRaSH Guides](https://trash-guides.info/) recommended quality
profiles, custom formats, scores, and quality definitions into Radarr and Sonarr on
a schedule, so the stack's acquisition tiers stay reproducible and current.

| | |
|---|---|
| Image | `ghcr.io/recyclarr/recyclarr:8` (digest-pinned) |
| Port | none (outbound only, bearcave network) |
| Config | `services/recyclarr/recyclarr.yml` (tracked, read-only mount) |
| Secrets | `config/recyclarr/secrets.yml` (generated by `scripts/setup.sh`, never committed) |
| Schedule | `CRON_SCHEDULE` — daily at 04:00 by default |
| Depends on | `radarr` + `sonarr` healthy, with restart cascade |

## What it syncs

- **Quality profiles** — the TRaSH 1080p Bluray + WEB tier: `HD Bluray + WEB`
  (Radarr) and `Bluray + WEB 1080p` (Sonarr; the guide's `WEB-1080p
  (Alternative)` definition, which is the Bluray-inclusive 1080p variant).
- **Custom formats** — every CF the profiles score (40 on Radarr, 37 on
  Sonarr as of the initial import).
- **Quality definitions** — TRaSH's allowed-size curves (14 entries per app).
- `delete_old_custom_formats: true` keeps the CF pool exactly in sync with the
  config: a CF removed from `recyclarr.yml` is deleted from the app on the next
  sync (safe because profiles are re-scored by the same run).

Changing profiles/tiers is a config edit in `services/recyclarr/recyclarr.yml`
(`recyclarr list quality-profiles radarr|sonarr` in the container shows the
available guide profiles and their `trash_id`s), then a manual sync or the next
scheduled run.

## Manual operations

```bash
# Run one sync now (uses the tracked config + generated secrets)
docker compose run --rm recyclarr sync

# Preview without changing anything
docker compose run --rm recyclarr sync --preview

# List guide profiles / custom formats available from TRaSH
docker compose run --rm recyclarr list quality-profiles radarr
docker compose run --rm recyclarr list custom-formats sonarr
```

## Secrets

`scripts/setup.sh` generates `config/recyclarr/secrets.yml` (mode 600) from
`.env`'s `RADARR_API_KEY` and `SONARR_API_KEY`, using recyclarr's `!secret`
substitution (file must sit next to the config, i.e. at `/config/secrets.yml`
in the container). Regenerate after rotating either key:

```bash
./scripts/setup.sh
```

## Notes

- The image is **rootless**: the container user comes from the compose
  `user:` property (interpolated from `PUID:PGID`), not the `PUID`/`PGID` env
  vars the other services use.
- The container runs `supercronic` in cron mode (PID 1); the healthcheck
  asserts that scheduler process is alive. Manual `docker compose run --rm`
  invocations exit after the command finishes.
- `read_only: true` with a `tmpfs` on `/tmp` keeps the filesystem read-only;
  logs, state, and downloaded guide resources land under `config/recyclarr/`.
- Upstream moves the `:8` tag; the pinned digest is bumped manually (see
  AGENTS.md's supply-chain policy). No CI dependency — the sync is
  host-side and touches no CI/CD surfaces.
