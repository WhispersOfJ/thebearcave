Certificate setup

Trust the HTTPS certificate on this device

Every service is served over HTTPS with a certificate signed by this stack's own local CA. Install the CA once per device and the browser warning disappears.

cert checking…
⬇ Download rootCA.pem
Linux · Debian / Ubuntu 
curl -kO https://__HOST__/rootCA.pem
sudo cp rootCA.pem /usr/local/share/ca-certificates/mkcert-rootCA.crt
sudo update-ca-certificates
Linux · Fedora / RHEL 
curl -kO https://__HOST__/rootCA.pem
sudo cp rootCA.pem /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Linux · Arch 
curl -kO https://__HOST__/rootCA.pem
sudo cp rootCA.pem /etc/ca-certificates/trust-source/anchors/
sudo update-ca-trust
macOS 
curl -kO https://__HOST__/rootCA.pem
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain rootCA.pem
Windows 
curl.exe -k -O https://__HOST__/rootCA.pem
certutil -addstore -f "ROOT" rootCA.pem
iOS / iPadOS
  1. In Safari, open https://__HOST__/rootCA.pem and allow the download
  2. Settings → General → VPN & Device Management → install the profile
  3. Settings → General → About → Certificate Trust Settings → enable full trust for the CA
Android
  1. In Chrome, open https://__HOST__/rootCA.pem and download it
  2. Settings → Security → Encryption & credentials → Install a certificate → CA certificate
  3. Select the downloaded file — done

Firefox (Linux/macOS) doesn't read the system store: open Settings → Privacy & Security → Certificates → View → Authorities → Import and pick rootCA.pem. rootCA.pem is the public certificate — the private key never leaves the server. Once installed, this page should show a valid padlock.
